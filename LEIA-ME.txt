Coloque aqui arquivos .pdb para a página da molécula usar.

1) Baixar: no site rcsb.org, abra a estrutura e use Download Files > PDB Format.
2) Salvar nesta pasta, com o código como nome. Exemplo: 1BPY.pdb
   - Com o nome igual ao código (1BPY.pdb), a página usa o arquivo no lugar de baixar do PDB.
   - Para outra molécula: ...molecula/?arquivo=NOME.pdb  (ou ?pdb=CODIGO, se o arquivo for CODIGO.pdb)
3) Suba a pasta para o GitHub.

Observações: o formato .pdb não existe para estruturas muito grandes (só .cif); a página lê apenas .pdb.
Estruturas com muitos milhares de resíduos geram modelos pesados para o celular.
