Molécula em tamanho real · realidade aumentada

DNA polimerase copiando o DNA

Tamanho real: 2,5 m

Para colocar a molécula no chão em tamanho real, abra esta página no celular: aponte a câmera para o QR Code ao lado.

Como usar
  • Aponte para o chão, a uns 3 m de distância, e mova o celular devagar até aparecer a grade.
  • Toque para posicionar. Depois, ande ao redor para ver a polimerase abraçando o DNA.
  • As cores das bases são as mesmas do jogo: A verde, T vermelho, C azul e G laranja.
Ferramenta da equipe: baixar os .glb

Salve os dois arquivos em assets/models/ e suba para o GitHub. Depois disso a página usa os arquivos prontos.
